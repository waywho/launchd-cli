# launchd-cli

## Pull requests

- Every PR description has at least one changelog heading: `### Added`, `### Changed`, `### Deprecated`, `### Removed`, `### Fixed` or `### Security`.
- Under each heading, write one line for each change. Start the line with `- `.
- When the PR merges, `waywho/pr-to-release` copies these lines into `CHANGELOG.md`. Without a heading, it uses only the PR title.
